# Política de Privacidade — Calculadora de Gastos Shopee

**Última atualização:** 11 de outubro de 2026

## 1. Objetivo

A Calculadora de Gastos Shopee é uma extensão para o Google Chrome desenvolvida para ajudar os usuários a visualizar e calcular os valores de seus pedidos na página **Minhas Compras** da Shopee.

Esta política explica quais informações a extensão acessa e como elas são utilizadas.

## 2. Dados acessados

Para realizar os cálculos, a extensão acessa informações exibidas na página de compras da Shopee, incluindo:

- Valores totais dos pedidos;
- Status dos pedidos, como comprado, cancelado ou reembolsado;
- Informações necessárias para identificar e contabilizar os pedidos exibidos na página.

A extensão utiliza essas informações exclusivamente para fornecer suas funcionalidades de cálculo e apresentar um resumo dos pedidos ao usuário.

## 3. Uso e armazenamento dos dados

As informações acessadas são processadas para calcular e exibir os totais dos pedidos.

A extensão não envia essas informações a servidores externos e não mantém um banco de dados próprio com os pedidos dos usuários.

Os resultados são apresentados diretamente na interface da extensão. Esta política deverá ser ajustada caso versões futuras passem a armazenar ou transmitir essas informações.

## 4. Compartilhamento de dados

A extensão não vende, comercializa ou compartilha com terceiros as informações dos pedidos acessadas durante sua utilização.

As informações são utilizadas exclusivamente para executar a funcionalidade principal da extensão.

## 5. Segurança

A extensão busca limitar o acesso às informações ao necessário para realizar os cálculos solicitados pelo usuário.

Recomenda-se que os usuários mantenham o Google Chrome atualizado e instalem a extensão apenas por fontes confiáveis.

## 6. Serviços de terceiros

A Calculadora de Gastos Shopee é uma extensão independente e não é afiliada, patrocinada ou oficialmente vinculada à Shopee.

A extensão não utiliza serviços externos para processar ou armazenar os dados dos pedidos, conforme as práticas descritas nesta política.

## 7. Alterações nesta política

Esta política poderá ser atualizada para refletir alterações nas funcionalidades da extensão ou nas práticas de tratamento de dados.

A versão atualizada será publicada na mesma página em que esta política estiver disponível.

## 8. Contato

Para dúvidas, solicitações ou esclarecimentos sobre esta política de privacidade, entre em contato pelo e-mail disponibilizado na página da extensão na Chrome Web Store.
