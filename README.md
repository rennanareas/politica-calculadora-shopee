# Política de Privacidade — Calculadora de Gastos Shopee

**Última atualização:** 10 de outubro de 2026

## 1. Objetivo

A Calculadora de Gastos Shopee é uma extensão para Google Chrome que auxilia os usuários a calcular o total de suas compras exibidas no site da Shopee.

## 2. Dados acessados

A extensão pode acessar informações exibidas nas páginas de pedidos da Shopee, como valores das compras e status dos pedidos, exclusivamente para realizar os cálculos disponibilizados pela extensão.

## 3. Uso e armazenamento dos dados

As informações acessadas são utilizadas para calcular e exibir os totais das compras. A extensão não transmite essas informações a servidores externos nem as compartilha com terceiros, desde que isso corresponda ao funcionamento efetivo da versão publicada.

## 4. Compartilhamento de dados

A extensão não vende nem compartilha dados pessoais dos usuários com terceiros, desde que não existam funcionalidades ou serviços integrados que realizem esse compartilhamento.

## 5. Segurança

A extensão busca limitar o acesso às informações ao necessário para executar sua funcionalidade principal.

## 6. Alterações nesta política

Esta política poderá ser atualizada quando houver mudanças nas funcionalidades ou nas práticas de tratamento de dados da extensão.

## 7. Contato

Para dúvidas sobre esta política de privacidade, entre em contato pelo e-mail informado na página da extensão na Chrome Web Store.
